# 阶段一：验证码测试集生成器

生成器在独立模块 `jkit-captcha-bench`，不进入 `jkit-captcha` 的业务类型。

四类各占四分之一，默认每类 25000 张：

- 纯英文：固定 4 位，只含字母，类别里同时有大写和小写
- 纯数字：固定 4 位，只含数字
- 英文数字混合：固定 4 位，每张至少有一个字母和一个数字
- 算术：二元四则，乘除优先、向零截断、除数不为 0、结果不为负；`+ - * /` 按序号轮转，除法约占四分之一

风格轴各自两个取值：字体（Verdana / Arial）、旋转（0° / 2°）、噪点、边缘线条、浅色网格纹理、字距、横向缩放。干扰线不穿过笔画，纹理只比底色深几个灰阶。

清单 `manifest.tsv` 回读路径、期望文本、类别、风格标签和算术结果。图片默认写到该模块的 `target/captcha-dataset`，不进版本库。

`mvn -pl jkit-captcha-bench test` 会跑生成器契约测试，不再排除 `BenchmarkSmokeTest`。

用同一入口抽了 800 张（每类 200，种子 20261101）：整串准确率 99.00%（算术 99.50%，数字 100%，英文 97.00%，混合 99.50%）。这只是抽样，10 万张全量在下一阶段。
