以下是10个复杂的常用的业务SQL示例，针对MySQL、Oracle、PostgreSQL和达梦数据库。每个示例都涉及高级查询操作，如窗口函数、递归查询、多表连接、聚合和子查询，适用于常见的业务场景。我将为每个SQL提供简要说明，解释其复杂性和用途。

1. **MySQL** - 计算销售数据的7天移动平均值（使用窗口函数）
   ```sql
   SELECT 
       date, 
       sales_amount,
       AVG(sales_amount) OVER (ORDER BY date ROWS BETWEEN 6 PRECEDING AND CURRENT ROW) AS moving_average_7day
   FROM sales;
   ```  
   **说明**：此查询使用窗口函数计算每日销售额的7天移动平均值，用于分析销售趋势。复杂性在于窗口函数的帧定义和聚合。

2. **Oracle** - 递归查询员工部门层次结构（使用CONNECT BY）
   ```sql
   SELECT 
       employee_id, 
       first_name, 
       manager_id,
       LEVEL as hierarchy_level
   FROM employees
   START WITH manager_id IS NULL
   CONNECT BY PRIOR employee_id = manager_id;
   ```  
   **说明**：此查询使用Oracle的CONNECT BY子句递归遍历员工-经理关系，生成部门层次结构。复杂性在于递归查询和层级计算。

3. **PostgreSQL** - 使用CTE和窗口函数为产品销售排名（前3名）
   ```sql
   WITH ranked_sales AS (
       SELECT 
           product_id, 
           sale_date, 
           amount,
           RANK() OVER (PARTITION BY product_id ORDER BY amount DESC) as rank
       FROM sales
   )
   SELECT * FROM ranked_sales WHERE rank <= 3;
   ```  
   **说明**：此查询使用公共表表达式（CTE）和RANK()窗口函数，找出每个产品的前3大销售记录。复杂性在于CTE封装和窗口函数分区。

4. **达梦（DM）** - 计算订单累计金额（使用分析函数，兼容Oracle语法）
   ```sql
   SELECT 
       order_id, 
       order_date, 
       amount,
       SUM(amount) OVER (ORDER BY order_date) AS cumulative_sum
   FROM orders;
   ```  
   **说明**：此查询使用SUM()窗口函数计算按订单日期排序的累计销售额。达梦数据库兼容Oracle语法，复杂性在于窗口函数的累积聚合。

5. **MySQL** - 多表连接和聚合分析客户消费（左连接和HAVING）
   ```sql
   SELECT 
       c.customer_id, 
       c.name, 
       COUNT(o.order_id) AS order_count, 
       SUM(o.total_amount) AS total_spent
   FROM customers c
   LEFT JOIN orders o ON c.customer_id = o.customer_id
   GROUP BY c.customer_id, c.name
   HAVING total_spent > 1000;
   ```  
   **说明**：此查询使用LEFT JOIN连接客户和订单表，并通过GROUP BY和HAVING过滤高消费客户。复杂性在于多表连接和聚合后过滤。

6. **Oracle** - 计算员工薪资与部门平均值的差额（使用窗口函数）
   ```sql
   SELECT 
       department_id, 
       employee_id, 
       salary,
       salary - AVG(salary) OVER (PARTITION BY department_id) AS diff_from_dept_avg
   FROM employees;
   ```  
   **说明**：此查询使用AVG()窗口函数计算每个员工薪资与其部门平均值的差额。复杂性在于窗口函数的分区和算术运算。

7. **PostgreSQL** - 递归CTE查询产品类别层次结构
   ```sql
   WITH RECURSIVE category_tree AS (
       SELECT id, name, parent_id
       FROM categories
       WHERE parent_id IS NULL
       UNION ALL
       SELECT c.id, c.name, c.parent_id
       FROM categories c
       JOIN category_tree ct ON c.parent_id = ct.id
   )
   SELECT * FROM category_tree;
   ```  
   **说明**：此查询使用递归CTE遍历产品类别的父子关系，生成类别树。复杂性在于递归查询和UNION ALL操作。

8. **达梦** - 行转列聚合销售数据（使用CASE语句模拟PIVOT）
   ```sql
   SELECT 
       product_id,
       SUM(CASE WHEN month = 'Jan' THEN sales ELSE 0 END) AS jan_sales,
       SUM(CASE WHEN month = 'Feb' THEN sales ELSE 0 END) AS feb_sales,
       SUM(CASE WHEN month = 'Mar' THEN sales ELSE 0 END) AS mar_sales
   FROM monthly_sales
   GROUP BY product_id;
   ```  
   **说明**：此查询使用CASE语句将月度销售数据转换为列，实现行转列。达梦数据库可能不支持原生PIVOT，因此使用聚合和条件逻辑。

9. **MySQL** - 使用CTE和子查询找出异常销售记录
   ```sql
   WITH daily_sales AS (
       SELECT 
           date, 
           product_id, 
           SUM(amount) as daily_amount
       FROM sales
       GROUP BY date, product_id
   )
   SELECT 
       date, 
       product_id, 
       daily_amount
   FROM daily_sales
   WHERE daily_amount > (SELECT AVG(daily_amount) * 2 FROM daily_sales);
   ```  
   **说明**：此查询使用CTE封装每日销售汇总，并通过子查询过滤出超过平均值两倍的异常记录。复杂性在于CTE和标量子查询的结合。

10. **Oracle** - 使用MERGE语句进行upsert（更新或插入）操作
    ```sql
    MERGE INTO target_table t
    USING source_table s
    ON (t.id = s.id)
    WHEN MATCHED THEN
        UPDATE SET t.value = s.value, t.update_date = SYSDATE
    WHEN NOT MATCHED THEN
        INSERT (id, value, create_date) VALUES (s.id, s.value, SYSDATE);
    ```  
    **说明**：此查询使用MERGE语句根据条件更新或插入数据，用于数据同步或清洗。复杂性在于MERGE的条件分支和事务处理。
